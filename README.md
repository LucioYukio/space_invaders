#  Space Invaders Style Game

Um jogo inspirado no clássico **Space Invaders**, desenvolvido com foco em lógica de programação, movimentação de inimigos em matriz, colisões, gerenciamento de entidades e gameplay arcade.

## Sobre o Projeto

Este projeto foi desenvolvido como prática de programação e desenvolvimento de jogos para uma matéria da faculdade, utilizando conceitos fundamentais como:

* Programação orientada a objetos
* Manipulação de listas e matrizes
* Sistema de colisão
* Controle de sprites
* Movimentação de inimigos
* Sistema de tiros
* Gerenciamento de estado do jogo
* Lógica de gameplay em tempo real

O objetivo do jogador é eliminar todas as naves inimigas enquanto desvia dos ataques e sobrevive o máximo possível.
